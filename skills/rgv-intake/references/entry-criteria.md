# Entry criteria — rgv-intake (gate zero)

Evaluated at gate zero, before any other step. Verdict semantics:
`references/gate-zero-verdicts.md` — any MUST-HAVE miss ⇒ REJECTED (hard stop); a
STRENGTHENER miss ⇒ at best IMPROVABLE. Every criterion gets PASS or MISS in READINESS.md.

## MUST-HAVES (any miss ⇒ REJECTED)

- **Corpus locatable and readable** — every candidate location (folders, repos, drives,
  chat/transcript exports) exists and opens. An inventory over unreachable sources
  indexes fiction.
- **Sources datable** — each source can carry a defensible date (mtime, content-stated
  date, an ID decoded from an export URL/filename). The evidence-recency rule dies
  without chronology; an undatable corpus defeats the whole process, not just this skill.
- **A scope statement exists** — an in/out boundary, however rough, for the step-1 gate
  to refine. Without one, the scope-confirmation gate has nothing to confirm.

## STRENGTHENERS (miss ⇒ IMPROVABLE)

- **Provenance notes** — who authored what, where each source lived — speed the MANIFEST
  and harden the lineage narrative.
- **Known-duplicate hints** — suspected copies named up front focus the byte-compare pass.
- **Prior indexes or inventories** — an earlier list of the corpus seeds the sweep and
  cross-checks completeness.
