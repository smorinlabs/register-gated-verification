# Entry criteria — rgv-seed (gate zero)

Evaluated at gate zero, before any other step. Verdict semantics:
`references/gate-zero-verdicts.md` — any MUST-HAVE miss ⇒ REJECTED (hard stop); a
STRENGTHENER miss ⇒ at best IMPROVABLE. Every criterion gets PASS or MISS in READINESS.md.

## MUST-HAVES (any miss ⇒ REJECTED)

- **Intake outputs on disk** — `archive/` + MANIFEST + INDEX; the interview drafts the
  goal from the INDEX's story paragraph.
- **A goal statement distinct from process** — the human can state the end state
  separately from the method. Step 1 refines the wording, but if no one can say what
  done looks like, the interview registers noise as D-entries.
- **A named human adjudicator with time to answer gates** — the seed IS an interview,
  human-paced end to end; an absent or hurried adjudicator makes every STOP a fiction.
- **Decision authority clear** — the named adjudicator can actually ratify; "I'd have to
  check with someone" is a missing must-have, not a smaller one.

## STRENGTHENERS (miss ⇒ IMPROVABLE)

- **Prior-process pain points written down** — "short briefs don't work"-class feedback
  feeds the meta-decision menu with evidence instead of defaults.
- **A draft oracle list** — candidate vendors/official docs to react to beats naming
  sanctioned sources cold.
- **An area-decomposition sketch** — even a rough cut speeds step 3's dependency ordering.
